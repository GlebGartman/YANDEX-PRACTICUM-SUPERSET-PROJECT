# YANDEX-PRACTICUM-SUPERSET-PROJECT
Проект по анализу цен и объемов предложений зерновых культур за январь–март 2025 года. В Apache Superset подготовлен датасет PostgreSQL, рассчитаны аналитические метрики, построены столбчатые, линейные графики и круговые диаграммы, настроены фильтры и итоговый дашборд
