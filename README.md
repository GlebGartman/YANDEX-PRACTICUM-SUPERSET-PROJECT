# 🌾 Анализ рынка зерновых в Apache Superset

Проект по анализу цен и объемов предложений зерновых культур за январь–март 2025 года. В Apache Superset подготовлен датасет PostgreSQL, рассчитаны аналитические метрики, построены столбчатые, линейные и круговые диаграммы, настроены фильтры и итоговый дашборд.

---

## 📌 Постановка задачи

В рамках проекта необходимо создать интерактивный дашборд для анализа предложений зерновых культур.

Дашборд должен помогать:

- сравнивать средние цены разных видов зерна
- анализировать динамику цен во времени
- оценивать объем предложений по покупателям
- фильтровать данные по типу зерна и периоду
- изменять временную гранулярность визуализаций

---

## 🗃️ Описание данных

Для анализа используется таблица `grain_prices` из схемы `public` подключения PostgreSQL.

Таблица содержит данные о ценах за килограмм разных видов зерновых у различных покупателей за январь–март 2025 года.

### Поля датасета

- `id` — идентификатор записи
- `dt` — дата внесения записи
- `grain_type` — тип зерна
- `price` — цена зерна, рублей за килограмм
- `amount` — объем предложения в тоннах
- `buyer` — покупатель

---

## 📐 Рассчитанные метрики

В рамках проекта в Apache Superset были созданы пользовательские метрики, позволяющие проводить анализ данных и использовать их в различных визуализациях.

### Средняя цена

```sql
AVG(price)
```

Метрика рассчитывает среднюю стоимость одного килограмма зерна.

**Metric key:** `average_price`  
**Label:** `Средняя цена, рубли за кг`

---

### Общая сумма предложения в рублях

```sql
SUM(price * amount * 1000)
```

Метрика рассчитывает общую стоимость предложения. Поле `amount` хранится в тоннах, поэтому при вычислении выполняется перевод в килограммы умножением на `1000`.

**Metric key:** `total_offer`  
**Label:** `Общая сумма предложения в рублях`

---

### Количество записей

```sql
COUNT(*)
```

Метрика используется для подсчета общего количества записей в датасете.

**Metric key:** `count`  
**Label:** `Количество записей`
